## Эмулятор CHIP-8

Этот эмулятор реализует стандартный процессор CHIP-8 (не Super CHIP-8).

## Что он может запускать

Он поддерживает большинство игр и программ в формате .ch8.

## ROM-образы

ROM-образы можно найти в этом репозитории:

- [CHIP-8 ROMs от kripod](https://github.com/kripod/chip8-roms) — тестовые образы и игры.

## Статус
- Базовая реализация. Возможны проблемы с производительностью на некоторых ROM-образах.
- Работает с Pong и простыми играми.

## Проблемы
- Некоторые игры работают некорректно или вовсе не запускаются.
- Звук не реализован.

## Использование
```bash
  git clone https://github.com/CBSDF/Chip8-Emulator.git
  cd Chip8-Emulator
  pip install pygame
  python main.py 
```
- Укажите путь к ROM-образу в файле `main.py`.

## Если Pygame не устанавливается

Выполните эту команду:
```bash
  pip install pygame-ce
```

## Почему я его создал?

Это был мой первый учебный проект, призванный помочь понять внутреннее устройство эмуляторов.
Я начал с основ: циклов процессора, работы с памятью, выборки (fetch) опкодов и отрисовки графики.

## Для кого этот проект?

Для начинающих из небольших регионов России и других стран.
Проект также призван показать, что даже если вы хотите изучать информатику,
но не имеете доступа к специализированным учебным заведениям,
этому можно научиться с помощью проектов с открытым исходным кодом и веб-сайтов.

## Маленький шаг к большой цели

Как я уже говорил, этот проект был создан для изучения основ.
Моим следующим крупным проектом станет эмулятор бортового компьютера Apollo (AGC) —
я хочу запустить на нем оригинальные программы NASA.
